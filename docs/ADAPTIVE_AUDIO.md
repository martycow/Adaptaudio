# Адаптивная музыка — модель

> Как музыка Cedar Station слушает игру и отвечает ей. Термины — в [GLOSSARY.md](GLOSSARY.md).
> Всё, что помечено **❓**, ещё не решено.

## Общая схема

```
          ┌──────────── Игра (Cedar Station) ────────────┐
          │                                              │
   Параметры 0..1        Режим (состояние)         События (разовые)
   Intensity, Tension…   Stealth, Chase…           Detected, PuzzleSolved…
          │                     │                          │
          ▼                     ▼                          ▼
   ┌──────────────────── Адаптивный движок ─────────────────────┐
   │  сглаживание → кривые отклика треков → переходы → стингеры │
   └───────────────────────────┬────────────────────────────────┘
                               ▼
                       Музыка (микс треков)
                               │
                               └──► обратно в игру: бит, такт, маркеры
```

## Три вида сигналов

| Вид          | Пример           | Как меняется      | Что делает с музыкой                                      |
|--------------|------------------|-------------------|-----------------------------------------------------------|
| **Параметр** | Intensity = 0.72 | Плавно, постоянно | Плавно меняет громкость слоёв, фильтры, плотность нот     |
| **Режим**    | Stealth → Alert  | Скачком, редко    | Переключает раздел музыки на ближайшей подходящей границе |
| **Событие**  | Detected         | Мгновенно, разово | Проигрывает стингер, открывает слой, сбивку               |

### Параметры

Каждый параметр — число от 0 до 1 со **сглаживанием** (slew): если игра резко прыгнула с 0.2
на 0.9, музыка доедет туда за заданное время, а не дёрнется.

| Параметр           | Смысл                                    | Типичный эффект                                       | Статус         |
|--------------------|------------------------------------------|-------------------------------------------------------|----------------|
| **Intensity**      | Сколько действия и энергии               | Барабаны, бас, плотность нот, громкость               | из `AGENTS.md` |
| **Tension**        | Сколько напряжения и неизвестности       | Диссонанс, открытие фильтра на пэде, райзеры, тремоло | из `AGENTS.md` |
| **Paranoia**       | Насколько опоссум не доверяет реальности | Детюн, «плывущая плёнка», реверс, сдвиг бита          | принят         |
| **PuzzleProgress** | Насколько решена текущая головоломка     | Открывает слои, усложняет аранжировку                 | принят         |
| **ThreatDistance** | Как близко угроза (1 = вплотную)         | Сердцебиение, низкий гул, громкость Tension-слоя      | ❓ предложение  |
| **Weather**        | Дождь или ясно                           | Слой Ambience: дождь, капли                           | ❓ позже        |

Стартовый набор (утверждён): Intensity, Tension, Paranoia, PuzzleProgress.
ThreatDistance и Weather — кандидаты на потом.

### Режимы игры

> ⚠️ **Путаница терминов.** В музыке «mode» — это **лад** (дорийский, фригийский…). Режимы игры в
> коде называем `GameMode`, а музыкальные лады — `Scale`. В UI: «Режим» и «Лад».

| Режим        | Ощущение                    | Темп            | Лад (идея)                      | Типичные слои                                 | Intensity                 |
|--------------|-----------------------------|-----------------|---------------------------------|-----------------------------------------------|---------------------------|
| **Explore**  | Любопытство, уют, PNW       | медленный       | пентатоника, лидийский          | Pad, Ambience, Ocarina                        | 0.0–0.3                   |
| **Stealth**  | Затаить дыхание             | медленный       | дорийский, натуральный минор    | Pad (тёмный), тихий пульс, Ambience           | 0.1–0.3                   |
| **Search**   | Тебя ищут                   | средний         | фригийский                      | + Perc, Tension-слой, бас                     | 0.3–0.5                   |
| **Alert**    | Тебя заметили!              | средний→быстрый | фригийский, уменьшённые аккорды | + Kick, Snare, стингер на входе               | 0.5–0.7                   |
| **Chase**    | Беги! Пик, «как Covox»      | быстрый         | минор                           | Всё: Kick, Bass, Arp, Lead, сайдчейн          | 0.8–1.0                   |
| **Relief**   | Выдох                       | медленный       | мажор, лидийский                | Pad (тёплый), Ocarina, Tongue drum            | 0.0–0.2                   |
| **Puzzle**   | Сосредоточенность, ритм     | стабильный      | лад сцены                       | Ритм-слой головоломки + открытые слои         | зависит от PuzzleProgress |
| **PlayDead** | Опоссум притворился мёртвым | —               | —                               | Почти тишина: сердцебиение, дыхание, Ambience | 0                         |

Список режимов утверждён: пять из `AGENTS.md` (Stealth, Search, Alert, Chase, Relief) плюс
Explore, Puzzle и PlayDead.

❓ Темп по режимам — менять ли его вообще? Смена темпа ломает ритм головоломок. Безопаснее
держать один темп в сцене и менять **плотность** (восьмые → шестнадцатые), что звучит как
ускорение.

### События

| Событие      | Реакция музыки                       | Привязка                       |
|--------------|--------------------------------------|--------------------------------|
| Detected     | Резкий стингер (удар + визг)         | следующая доля                 |
| Lost         | Падающий стингер                     | следующий такт                 |
| PuzzleStep   | Нота в ладу (игрок «играет»)         | мгновенно или к ближайшей 1/16 |
| PuzzleFail   | Диссонанс или сбой                   | мгновенно                      |
| PuzzleSolved | Стингер-аккорд + открыть слой        | следующий такт                 |
| Heartbeat    | Удар сердца (для PlayDead и Stealth) | следующая доля                 |

## Как трек реагирует на игру

У каждого трека две ручки:

- **Volume** — обычная громкость в миксере.
- **Influence** (0..1) — насколько трек следует за игрой. 0 — играет всегда одинаково,
  1 — полностью управляется кривыми отклика.

**Кривая отклика** связывает параметр игры с параметром трека. Пример:

| Трек             | Параметр игры  | Что меняется                | Форма кривой                |
|------------------|----------------|-----------------------------|-----------------------------|
| Pad              | Tension        | Cutoff фильтра              | плавно растёт от 0 до 1     |
| Kick             | Intensity      | Громкость                   | 0 до 0.4, потом резко вверх |
| Hats             | Intensity      | Вероятность нот (плотность) | линейно                     |
| Bass             | Intensity      | Громкость + дисторшн        | ступенька на 0.5            |
| Arp              | Intensity      | Громкость                   | только выше 0.8 (пик)       |
| Lead             | PuzzleProgress | Громкость                   | открывается при решении     |
| Все мелодические | Paranoia       | Детюн, wow/flutter          | экспонента                  |

Итоговое значение: `final = base + Influence × (curve(param) − base)`.

### Техники адаптивности

| Техника                           | Суть                                                                  | Когда                          |
|-----------------------------------|-----------------------------------------------------------------------|--------------------------------|
| **Вертикальные слои**             | Все треки играют синхронно, меняется только их громкость              | Параметры (Intensity, Tension) |
| **Горизонтальная смена разделов** | Переход к другому клипу или разделу на музыкальной границе            | Режимы                         |
| **Стингеры**                      | Короткие разовые фразы поверх музыки                                  | События                        |
| **Плотность**                     | Вероятность каждой ноты в паттерне (как conditional trigs у Elektron) | Intensity → больше нот         |
| **Модуляция**                     | Фильтр, дисторшн, детюн, реверб по кривой                             | Tension, Paranoia              |
| **Гармоническое напряжение**      | Диссонирующий слой или смена аккордов                                 | Tension                        |

## Переходы между режимами

Переход описывается в **матрице переходов** (откуда → куда):

| Поле                | Варианты                                                                         |
|---------------------|----------------------------------------------------------------------------------|
| **Квантование**     | сразу · следующая доля · следующий такт · конец фразы (4/8 тактов) · конец клипа |
| **Кроссфейд**       | длительность в долях или мс                                                      |
| **Переходный клип** | опционально: сбивка, райзер, стингер                                             |
| **Гистерезис**      | минимальное время в режиме, чтобы музыка не «мигала»                             |

Пример:

| Откуда → Куда      | Квантование | Кроссфейд | Переходный клип                  |
|--------------------|-------------|-----------|----------------------------------|
| Stealth → Search   | такт        | 2 доли    | —                                |
| Stealth → Alert    | **доля**    | 0         | стингер Detected                 |
| Search → Alert     | доля        | 0         | стингер Detected                 |
| Alert → Chase      | такт        | 1 доля    | сбивка барабанов                 |
| Chase → Relief     | конец фразы | 4 доли    | «выдох»: реверс-тарелка + аккорд |
| любой → PlayDead   | сразу       | 0.3 с     | — (резкая тишина — это эффект)   |
| PlayDead → Stealth | такт        | 2 такта   | —                                |
| по умолчанию       | такт        | 1 доля    | —                                |

## Ритмические головоломки

В игре будут все три вида. Каждый вид — это музыкальная фраза, привязанная к биту движка.

| Вид         | Что делает игрок                                     | Что делает музыка                                                                 | Проверка                                       |
|-------------|------------------------------------------------------|-----------------------------------------------------------------------------------|------------------------------------------------|
| **Timing**  | Нажимает в такт                                      | Ведёт ритм. Попадание играет ноту в ладу, промах — диссонанс или «глухой» удар    | Окно допуска вокруг доли (например, ±60 мс)    |
| **Pattern** | Собирает ритм из элементов на сетке шагов            | Проигрывает собранное в цикле. Чем ближе к решению, тем больше растёт PuzzleProgress и открываются слои | Сравнение сетки с целевым паттерном |
| **Echo**    | Повторяет услышанную фразу (call and response)       | Играет «вопрос», ждёт такт, слушает «ответ»                                       | Порядок нот + окно допуска по времени          |

Общие правила:

- Головоломка живёт в режиме **Puzzle**. Темп сцены во время головоломки не меняется.
- **Paranoia** может «испортить» головоломку: сдвинуть бит, подменить ноту в Echo-фразе,
  показать на сетке Pattern ложный шаг. Насколько сильно — решает гейм-дизайн; движок даёт ручку.
- Окна допуска и задержка ввода калибруются в настройках игры, как в любой ритм-игре.

## Музыка → игра

В игре это делает FMOD через колбэки `TIMELINE_BEAT` и `TIMELINE_MARKER`. Adaptaudio
показывает то же самое в Playtest. Музыка отдаёт игре:

- **бит и такт** (`beat`, `bar`, время до следующей доли) — для ритмических головоломок и анимаций;
- **маркеры** в клипах (например, «тут кульминация») — игра может синхронизировать события;
- **текущий режим и раздел** — для отладки.

## Как это ложится на FMOD

В игре музыку играет FMOD (см. [ARCHITECTURE.md](ARCHITECTURE.md#связь-с-игрой)). Модель
Adaptaudio специально устроена так, чтобы переноситься в FMOD почти один к одному:

| Adaptaudio | FMOD Studio |
|---|---|
| Сцена (музыка одной локации со всеми режимами) | Музыкальное событие, например `music/station_night` |
| Трек | Audio track в событии |
| Раздел (Section) | Регион таймлайна с loop region |
| Клип | Инструмент на треке со стемом (single или multi instrument) |
| Параметр игры (Intensity, Tension, Paranoia, PuzzleProgress) | Параметр FMOD с тем же именем и диапазоном 0..1 |
| Сглаживание (slew) | Seek speed параметра |
| Кривая отклика × Influence | Автоматизация громкости или эффекта трека по параметру. Influence запекается в форму кривой |
| Режим игры | Параметр с метками `Mode` + transition regions с условием на `Mode` |
| Квантование перехода | Квантование transition region (такт или доля) |
| Переходный клип | Transition timeline |
| Гистерезис | Остаётся в игре: C#-код не меняет `Mode` чаще заданного |
| Событие → стингер | Переход внутри события по параметру-триггеру с квантованием, или отдельное one-shot событие, которое игра запускает по колбэку следующей доли |
| Маркер в клипе | Маркер таймлайна → колбэк `TIMELINE_MARKER` |
| Бит и такт | Tempo marker → колбэк `TIMELINE_BEAT` |
| Вероятность нот | Стемы разной плотности + шанс срабатывания инструмента |
| Эффекты Paranoia | Эффекты на треке или шине с автоматизацией по `Paranoia` |
| Сценарий Playtest | Не переносится: это инструмент прототипа |

## Пример сценария (для Playtest)

```
0:00  Explore   Intensity 0.1  Tension 0.1
0:30  Stealth   Tension → 0.4 за 10 с
0:50  Event Detected
0:50  Alert     Intensity → 0.6
1:05  Chase     Intensity → 1.0 за 4 с       ← пик «как Covox»
1:50  Event Lost
1:55  Relief    Intensity → 0.1 за 8 с, Tension → 0
2:20  Puzzle    PuzzleProgress 0 → 1 за 40 с (с событиями PuzzleStep)
3:00  Event PuzzleSolved
```

Такие сценарии хранятся в проекте и проигрываются в Playtest кнопкой: сразу слышно, как
музыка проходит весь путь, без запуска игры.
